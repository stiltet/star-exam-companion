# Security Policy

## Supported Versions

The following versions of STAR Exam Companion are currently supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ |
| < 1.0.0 | ❌ |

Security fixes are generally provided only for the latest released version.

## Reporting a Vulnerability

The security of STAR Exam Companion is taken seriously and security is a mandatory part of Star QA Verification. If you believe you have discovered a security vulnerability, please report it privately.

### Please Do Not

Please do not disclose security vulnerabilities publicly through GitHub Issues, Discussions, social media, blog posts, or other public channels before the issue has been reviewed and addressed.

### How to Report

Please use GitHub's private vulnerability reporting feature:

1. Go to the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Provide a detailed description of the issue, including:
   - Steps to reproduce
   - Potential impact
   - Affected version(s)
   - Proof of concept (if available)

If GitHub private vulnerability reporting is unavailable, please contact the repository maintainer directly through GitHub.

### What to Expect

This project is maintained by a single volunteer maintainer. While I will make a best effort to review and respond to security reports, response times may vary depending on availability and the complexity of the issue.

After a report is received:

1. The report will be reviewed and assessed.
2. Additional information may be requested if needed.
3. If the vulnerability is confirmed, a fix will be developed and released when possible.
4. A security advisory or release note may be published once a fix is available.

### Responsible Disclosure

Please allow a reasonable amount of time for investigation and remediation before publicly disclosing a vulnerability.

I greatly appreciate responsible disclosure and the efforts of security researchers who help improve the security of this project.
