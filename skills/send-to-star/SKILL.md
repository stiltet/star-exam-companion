# Send to Star

Use the bookmarklet to save a reading page from a Google Skills browser session to the private
store on the Star Exam Companion server.

1. Start Star Exam Companion on the computer that will keep the private copy.
2. Open the Agentic Architect Read Aloud page and copy the Send to Star bookmarklet. Add the copied
   text as the URL of a browser bookmark named **Send to Star**.
3. In the same browser, sign in to Google Skills and open a reading page in course 1786 or 1832.
4. To save only part of the page, select that reading text. Otherwise, the bookmarklet uses the
   page's main content. Choose **Send to Star**.
5. Keep the local capture tab open until it confirms the page was saved. The page is stored outside
   the repository and build output, on the server that received it.
6. Open the course in Read Aloud to confirm the saved page is listed. Repeat for other reading
   pages; saving the same page again replaces its existing private copy.
